# Calibrated-Open-Set-Recognition-for-Robust-Plant-Disease-Diagnosis
Developed an open-set plant disease recognition system using EfficientNetV2-B0. Compares laboratory, mixed-domain, and outlier-exposure training with calibrated OOD detection to identify unseen diseases and non-plant images. Includes leakage-aware evaluation, robustness testing, and a deployable known/reject predictor.
